# House Price Prediction System

## Mini-Project Overview
A simple Python program designed to estimate real estate prices based on property size (square footage).

## Real-World Problem Statement
Homebuyers and sellers often find it difficult to estimate fair market value for real estate. This project automates price estimation using basic mathematical logic.

## AI/ML Approach
- **Type:** Supervised Learning (Regression)
- **Concept:** Predicts a continuous value (price) based on continuous input features (square footage).
- **Future Enhancement:** Train a Scikit-Learn `LinearRegression` model on real housing data.
